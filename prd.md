# NULL ORBIT

## Product intent

NULL ORBIT combines a browser-generated 3D art exhibition and an abstract Object Studio. The exhibition introduces an impossible machine inside a speculative observatory; the studio lets visitors personalize the sculpture as a wallpaper to download, save or share. A striking composition is the visual goal; absolute originality and market demand are not verified claims.

The project remains at the approved `D:\Gpt projs\null-orbit` location. On 18 October 2026 the user requested keeping Object Studio and removing World Studio and Scenery Studio. This supersedes earlier additive world/scenery plans. The original exhibition and all Object Studio capabilities remain in scope. No hosting or dependency change is part of this increment.

## Audience and outcome

Creators, students, streamers, designers and curious visitors can make abstract backgrounds for phones, desktops, presentations or thumbnails. The primary creator journey is choose a preset → customize → select format → download, save or share. It requires no account, upload or paid service.

Visitors who want to explore retain the exhibition, narrative, three reality modes, drag interaction, initiation sequence, optional synthesized sound, reduced-motion preference and static fallback.

## Current scope

- Near-black, ivory, chrome and vermilion exhibition with a procedural sculpture and responsive editorial layout.
- `#studio` workspace with Chrome Eclipse, Solar Core, Signal Storm, Porcelain Orbit, Deep Space and Liquid Ember presets.
- Real 3D controls for reality mode, shape, material, accent/background, lighting, motion speed, particles, zoom and orientation.
- Desktop, Phone, Square and Ultrawide previews and exact-size PNG exports.
- Silent WebM live-wallpaper export with 6/10-second duration, 720p–4K quality and up to 240 fps when the actual browser encoder supports the target. Progress, cancellation and capability failures remain explicit.
- Up to 20 named browser/origin favorites and versioned share URLs restoring validated settings, pose and aspect ratio.
- Editing with pause/reduced motion and readable storage, clipboard, rendering and export failures.

Procedural readings are labeled art/simulation. There are no sensors or fabricated commercial outcomes. A wallpaper player is needed to apply exported video; export itself does not install an OS wallpaper.

## Feature retirement and data

World Studio, both cinematic and legacy variants, and Scenery Studio are removed from active navigation, source modules and public assets. Retired `#worlds` and standalone `?world=`, `?scene=` or `?scenery=` links recover to Object Studio after removing those parameters. Removed document payloads are not reinterpreted as object designs.

Existing browser collections are left untouched; retirement performs no deletion, migration or overwriting. Historical source, assets and specifications are retained in the local-only, Git-ignored archive `work/removed-world-studios-2026-10-18/`. This archive is absent from fresh clones. The old editors and landscape catalogue are not part of the current product.

## Success measures and limits

[requirements.md](requirements.md) defines the observable acceptance criteria, including REQ-42 for removal and retained behavior. [status.md](status.md) owns actual evidence and remaining checks. Unit tests, build success, browser workflows, GPU output and production readiness are separate claims.

The intended user outcome is a complete create → export → share journey in one visit. Demand, completion rate, load speed and frame rate have not been established as measured product results.

## Outside current scope

AI generation is excluded. World/scenery creation, accounts, cloud collections, community galleries, payments, analytics, publication, backend services, music-reactive uploads, native wallpaper installation, arbitrary asset uploads, MP4 conversion, iPhone Live Photo creation and production-readiness guarantees are outside this version.
